# 分类器说明

## 1. 概述

分类器用于根据视频信息（如标题、UP主等）自动将视频归类到不同的目录中。系统提供了两种分类器类型：基础分类器和内容分类器。

## 2. 内容分类器

内容分类器通过正则表达式匹配视频信息来决定视频的分类。以json文件的形式提供。

内容分类器包含以下字段：

- `name`：分类器名称
- `output_dir`：匹配成功时应选择的输出目录
- `regexp`：用于匹配的正则表达式配置
- `priority`：分类器优先级（默认为9，数字越小优先级越高）
- `with_upinfo`：控制最终输出目录的布尔值，如果为 `True`，最终路径会包含UP主信息

其中的regexp字段还包括以下子字段:

- `common`：用于所有字段匹配的通用正则表达式列表
- `title`：专门用于标题匹配的正则表达式列表  
- `up`：专门用于UP主匹配的正则表达式列表

### 2.1. 匹配逻辑

内容分类器按照以下顺序进行匹配：

1. **UP主匹配**：使用 `regexp.up` 中的正则表达式匹配UP主
2. **标题匹配**：使用 `regexp.title` 中的正则表达式匹配标题
3. **全匹配**：使用 `regexp.common` 中的正则表达式同时匹配标题和UP主

### 2.2. 优先级系统

- 分类器按照优先级顺序进行匹配，优先级数字越小越先执行
- 同一优先级的分类器按照加载顺序执行
- 一旦有分类器匹配成功，就会返回结果，不再继续匹配其他分类器

### 2.3. 配置文件

分类器配置通过 JSON 文件加载，系统会自动加载 `classifiers` 目录下所有 `.json` 文件，也可以通过`-c DIR`或者`--classifiers DIR`选项来手动指定一个目录(此时就不会再加载默认路径下的分类器)。

示例配置结构：
```json
{
  "分类器名称": {
    "output_dir": "输出目录路径",
    "regexp": {
      "common": ["通用正则表达式"],
      "title": ["标题正则表达式"],
      "up": ["UP主正则表达式"]
    },
    "priority": 优先级数字,
    "with_upinfo": 是否包含UP主信息
  }
}
```

### 2.4. 最终路径生成

根据 `with_upinfo` 字段决定最终的输出路径：

- 如果 `with_upinfo` 为 `False`：返回 `output_dir`
- 如果 `with_upinfo` 为 `True`：返回 `output_dir/UP主名称`

如果没有分类器匹配成功，默认返回 `unknown` 目录。
